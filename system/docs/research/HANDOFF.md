## What is done and verified

**RE4 GameCube: model replacement works end to end, both sides, through the app.**

```
characters op=use character=<collection slug> game_id=78ab9efa2e310db4 slot=player    -> Sonic as the player, on screen
characters op=use character=<collection slug> game_id=78ab9efa2e310db4 slot=enemies   -> 58 of 60 enemy packs, on screen
```

Evidence: `docs/research/evidence/sonic-in-re4gc-mercenaries.jpg`, `sonic-enemies-app-built.jpg`, `sonic-zombie-grapple-app-built.jpg`.

Module: `system/gbox/re4gc_zombies.py` (CLI: `python -m gbox.re4gc_zombies --iso ... --model ... --out ...`), with
`system/gbox/rig_roles.py` for joint roles from geometry. 20 tests across `test_rig_roles.py`, `test_re4gc_zombies*.py`.
`characters.build_re4_enemies` is the app path; `char_swap.build_mod` now carries `em*.drs` as well as `pl*.drs`.

The two rules that made it work (both cost rounds to find):
* **pad every replacement to the original file size** - a shorter file written in place leaves the original's tail readable and the
  game draws the ORIGINAL out of it;
* **the model's own bounding box is not rewritten** - a rewritten box freezes the title.

The 2 packs that do not fit are degenerate skeletons (2 and 3 bones) and are refused on purpose.
