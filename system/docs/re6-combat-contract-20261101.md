Observed causes and corrections:

- A downstream angular tolerance bypassed the strict laser-segment test. Full-tick reproductions fired five times in 0.6 seconds with the laser 50 cm short or 40 cm sideways. Only measured body contact now authorizes aimed fire; past hits cannot widen that test.
- Old LOS or floor-navigation rejection could suppress fresh body contact. Current valid contact overrides that stale visibility evidence. No-damage cooldowns remain, so contact alone does not remove an ammunition-conservation cooldown.
- Crowd control selected lock-assisted aimed fire, then renewed a separate gun-down timer that vetoed its own raise. The aimed-fire branch no longer renews that timer. Close melee, flanking escape and the worker's custom tablet/retreat behavior are preserved.
- Snapshot ammunition previously came from inventory slot zero regardless of the equipped gun. It now resolves the equipped wheel index. Empty magazines cannot trigger between reload requests. Gun quick shots, including damage retaliation, require ammunition and measured contact; melee remains available.
- Finite ammunition exposed a further loop: 49 reload requests against an empty gun while other owned guns remained loaded. The follow-up reads counts by wheel index, allows a short reload grace, then selects an existing loaded weapon through the native equipment controller. Known-empty preferences cannot pull it back to the empty gun. An explicitly locked operator weapon stays locked. No ammunition is created by this fallback.
