# Tool contracts

Every tool is registered with `@tool(name, version, In, Out, ...)` in `gbox/tools.py` and exposes the plan §19 fields through `GET /api/tools`. The full machine-readable list is in `schemas/tools.json`, generated by `gbox schemas`.

## Adding a tool

1. Define Pydantic `In` and `Out` models.
2. Write `fn(inp, ctx)`. Call `ctx.artifact(name, bytes, media_type, **provenance)` for every output file.
3. Write `validate(out, artifacts) -> list[str]` that checks the artifacts and not just the claims.
4. Add a `check(config)` that returns a reason string when the backing program is missing.
5. Add a test.

Final job states: `succeeded` (validated), `invalid`, `failed`, `rejected`.
