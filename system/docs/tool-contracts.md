# Tool contracts

Every tool is registered with `@tool(name, version, In, Out, ...)` in `gbox/tools.py` and exposes the plan §19 fields through `GET /api/tools`. The full machine-readable list is in `schemas/tools.json`, generated by `gbox schemas`.

| Tool | Permissions | Validator (runs on control plane) | Status |
|---|---|---|---|
| echo_artifact | read | artifact hash/length match | tested |
| scan_library | read | unique ids; on_accept → catalog + profiles | tested |
| launch_game | execute | schema | failure path tested; real emulator untested |
| session_op | execute | schema | untested against a real runtime |
| read_memory | read | artifact length/hash | protocol tested via fake |
| write_memory | memory_write | schema; rollback bytes saved | rejection tested |
| get_frame | read | PNG signature + IHDR + hash | tested (real capture) |
| export_asset | read | UAP validator + glTF round trip | tested |
| open_in_blender | read | vertex/bone counts vs UAP | written, unverified |
| analyze_binary | read | artifact counts | written, unverified |
| ue_steam | read, execute | schema; refuses anti-cheat games before opening paks | synthetic paks tested; live read-only check on owned UE 4.27 games (docs/ue_steam.md) |
| llm_complete | network | non-empty; output is a hypothesis | smoke-tested with Ollama |

## Adding a tool

1. Define Pydantic `In` and `Out` models.
2. Write `fn(inp, ctx)`. Call `ctx.artifact(name, bytes, media_type, **provenance)` for every output file.
3. Write `validate(out, artifacts) -> list[str]` that checks the artifacts and not just the claims.
4. Add a `check(config)` that returns a reason string when the backing program is missing.
5. Add a test.

Final job states: `succeeded` (validated), `invalid`, `failed`, `rejected`.
