# Live Mods controls and per-computer copies

Search, game, writer, favorites, build kind, play history and sort controls update the list immediately.
The initial sort stays newest first. Choosing another computer refreshes its inventory immediately and
selects **On selected PC first**, with newest builds first inside each availability group. The sort menu
can select any other order afterwards. Inputs and image carousel positions remain in view state.

Each computer has its own inventory, download jobs, completion overrides and download menu. Switching the
selector during a transfer does not redirect that transfer or display its progress as another computer's.
Downloaded builds have the top-left broken-build action; absent or still-downloading builds do not.
Existing investigation information remains accessible through its ticket badge. The selected-PC download
fills a vertical bar from bottom to top on the card, using the worker job's reported percentage. Completion
or failure removes the progress bar. Download completion is confirmed by the successful job, not a timer.

The **donor > target** mapping arrow opens the shared Three.js retarget editor on the exact donor/game/slot.
Its recorded reduction section links only fitting jobs whose output build name and target game match this
build; donor filtering keeps another cast member's history separate. It opens the existing before/after
review with triangle counts and allocation information. Older builds without matching jobs or expired
geometry are explicitly unavailable, never reconstructed from a newer build or the live adjustment preview.
